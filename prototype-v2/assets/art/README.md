# V2 prototype art

Estos assets fueron generados para el prototipo mediante la herramienta integrada de generación de imágenes de Codex en agosto de 2026.

## Inventario

- `grukh-bridge.png`: escenario pintado del puente, sin personajes ni UI.
- `aldric.png`: retrato de Aldric con fondo transparente.
- `grukh.png`: retrato de Grukh con fondo transparente.

## Dirección usada

- Fantasía adulta y realista, pintada en 2D.
- Puente de piedra durante el crepúsculo, con Varnock al fondo.
- Paleta gris azulada, verde desaturado, carbón y luces ámbar.
- Aldric como mercenario humano con equipo práctico y gastado.
- Grukh como troll exiliado, inteligente y amenazante sin presentarlo como inherentemente malvado.

Los retratos se generaron como piezas independientes y luego se procesaron mediante la misma herramienta para obtener alpha real. No contienen UI ni texto incrustado.

## Distribución

El repositorio todavía no tiene licencia. Antes de distribuir públicamente estos assets se debe revisar y documentar la política de uso aplicable al contenido generado.
