# Feedback - Demo 2026-02-07

## UI / Legibilidad

- **Letra muy chica:** El texto en la terminal es demasiado pequeño para leer cómodo.
- **Párrafos cortados:** Los textos largos se cortan en la terminal y no se pueden leer completos. Falta word-wrapping o control del ancho de línea.

## Gameplay / Combate

- **Falta dinamismo en las peleas:** La experiencia se siente como solo apretar teclas, no como jugar. Buscar que las decisiones del jugador tengan más peso y que el combate sea más interactivo.
